# 2rism ✈️

A responsive travel discovery website with destination browsing, hotel listings, activity categories, and a travel tips section.

**[🔗 Live Demo](https://tatianaander.github.io/2rism/)**

---

## About

2rism is a travel platform UI concept built with HTML, CSS, and JavaScript. It showcases a rich, image-heavy layout with a search interface, destination cards, hotel listings, and activity sections — all fully responsive.

## Features

- Personalized greeting UI with user avatar
- Destination search with location, activity, date, and guest filters
- Popular destinations gallery (USA, Europe)
- Hotel and restaurant listings with star ratings and country flags
- Travel tips and advice section
- Activity categories (Sailing, Climbing, Skiing, Hiking)
- Newsletter subscription section
- Multi-column responsive footer

## Technologies

- HTML5
- CSS3 (Flexbox, responsive layouts)
- JavaScript
- SVG icons

## Getting Started

```bash
git clone https://github.com/TatianaAnder/2rism.git
cd 2rism
# Open index.html in your browser
```

Or visit the **[live demo](https://tatianaander.github.io/2rism/)** directly.
